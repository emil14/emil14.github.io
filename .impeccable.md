## Design Context

### Users
Primarily potential employers and clients evaluating Emil through his introduction, projects, code and future articles. Prioritize concrete work and an easy path to his GitHub profile. Specific experience, contact details and project selection still need real content.

### Brand Personality
Simple, personal, lightly playful. Avoid a corporate landing page.

### Aesthetic Direction
A minimal editorial portfolio with a broad layout, restrained green-grey neutrals and forest-green accent. No star or Claude-like orange palette. Real page navigation styled as tabs; project-first stories, English and Russian, light and dark modes.

### Design Principles
- Keep the code small and easy to change: native HTML, CSS and JavaScript.
- Keep the initial structure provisional.
- Use typography and small details instead of elaborate effects.
- Never invent biographical claims or published articles.
- Preserve keyboard access, readable contrast and mobile layouts.
