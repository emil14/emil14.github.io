Personal project

Penoma

Voice notes, LLM-assisted editing and semantic search inside Telegram.

2024 · GitHub contributions
  • Go
  • React
  • LLMs
  • PostgreSQL

The product

A personal product experiment for capturing and organizing notes in Telegram. Voice messages are transcribed and edited into readable Markdown notes; a Mini App provides a browser-based note interface.

The engineering

The Go backend exposes a GraphQL API to the React Mini App. Saved notes are embedded for semantic search in PostgreSQL with pgvector. Background jobs update those embeddings, with note snapshots used to check whether a job still refers to the current note version.

Beyond the model call

The repository also includes streamed assistant replies, subscriptions and payment integration, user-event tracking and push-message infrastructure. I worked across the backend, Telegram integration and web interface.
