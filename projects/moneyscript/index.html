Personal / Private experiment

MoneyScript

A private hobby project exploring LLM-assisted trading and the engineering behind autonomous decision systems.

  • Python
  • LLMs
  • Evaluation

The experiment

I’m building a small research system that assembles market context, asks models for forecasts and proposed actions, reviews their answers and carries out accepted actions through a paper-trading interface. It’s a personal playground for ideas I want to test in a working system.

The engineering

The interesting part is the deterministic runtime around the model calls: assembling inputs, checking structured replies, validating permitted actions and recording what happened. Journals and replay tooling help trace decisions and compare configurations on recorded inputs, rather than judging a change from one plausible-looking model answer.

My work

I design and develop the system, including model context, execution checks, tests, evaluation tooling and the workflow for running experiments.

Status

An ongoing hobby experiment with simulated execution. The source code is private; this page shares a high-level engineering overview.
