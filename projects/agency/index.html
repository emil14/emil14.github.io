Open source / Go library

Agency

A Go-idiomatic library for applied generative AI.

  • Go
  • LLMs
  • Library design

The project

Agency provides a small core for composing generative-AI operations and separating application logic from model-provider implementations. Its examples cover chat, RAG and multimodal operations.

My involvement

I worked on Agency as a maintainer and wrote introductory articles about using the library in Go.
