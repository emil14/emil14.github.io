Personal project

EQT Bot

A Telegram financial tracker combining conversational input, a Mini App and TON transaction synchronization.

2023 · GitHub contributions
  • Go
  • React
  • GraphQL
  • TON

The product

EQT Bot brings fiat accounting and crypto-account tracking into Telegram. A conversational assistant accepts text or voice input, while the Mini App provides account balances and transaction views.

The engineering

The Go backend connects an LLM assistant to account and transaction operations through structured function calls. A GraphQL API serves the React interface. The project includes TON account synchronization, integration tests and user-interface test scenarios.

A reusable part

TON Syncer was built for this project and published as a separate service and library. It handles the blockchain-to-database synchronization work independently of the bot interface.

Hackathon experience

Our team took the project to a TON hackathon and reached the final, without winning the event. The experience combined building a product with presenting it to a jury. More event details and materials will be added when recovered.
