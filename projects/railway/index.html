Manaraga → Railway infrastructure

AI assistant for Serbia’s railways

An assistant for railway infrastructure engineers. They ask about equipment, the network or a maintenance procedure, and it pulls the answer from the right system with a reference to the source. I design the system, run the team and handle the work with the customer.

One chat, many systems behind it

The data an engineer needs is spread across different systems. The agent works out what kind of question it is, goes to the system that owns that fact and answers with a reference. Everything runs in the customer’s closed network, in line with Serbian information security law.

RAG without vector embeddings

The usual way to answer questions over documents is a vector database. Equipment manuals already have a table of contents, so I suggested relying on that instead. We tested it in January 2026, it held up, and it is what runs in production. The agent finds the right chapters and reads them whole, so answers point to specific pages and the document edition.

Evals

Together with QA we built datasets for each capability: documents, monitoring, inventory, web search. They are used to pick the model and to check releases.

The metric took a few tries. An average score hid failures in one of the languages, so I pushed for scoring each criterion by its worst language and counting a case only when all three runs pass.

Where we went simpler

Everyone agrees that extra complexity should be avoided, and everyone keeps tripping over it anyway. Here I managed to hold on to the simple options, and I’m quietly proud of that.

Could have builtWhat we didWhy
KubernetesDocker ComposeKubernetes was considered; I suggested not bringing it in. Compose is enough for this load and can move to a cluster later without a rewrite.
Vector databaseChapters and full-text search in PostgreSQLManuals already have structure. One fewer service to run in a closed network.
An agent that watches the network on its ownAnswers on request from live monitoringAn assistant answers questions. Live monitoring data covers what engineers ask.
Recognising an archive of scansLeft it outAll the data the agent needed was already in the registry.
