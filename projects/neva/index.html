Neva

A dataflow language built around nodes and message passing.

2021–2026 · GitHub activity
  • Language design
  • Go
  • Concurrency

The idea

Instead of a sequence of instructions, programs are networks of nodes that exchange immutable messages. Parallel execution is part of the language’s design.

My work

Neva is my own long-running language project: language design, compiler work and an exploration of concurrency and developer experience. It went well beyond a prototype, but has not reached production adoption.

Current status

Development is on pause while I focus on other work.
