# Repository instructions

## Delivery

- By default, commit every completed change and push it directly to `master` without asking for additional confirmation.
- An explicit instruction for the current task (for example, review only, do not commit, or use a separate branch) overrides this default.
- Check the relevant changes before pushing. Preserve unrelated work and never force-push `master`.
- Pushes to `master` deploy the website to GitHub Pages. After changing the site or deployment workflow, verify the workflow and public site before reporting deployment as complete.

## Website

- Keep the site simple: plain HTML, CSS and JavaScript, no build step.
- Maintain English and Russian content, light and dark themes, mobile layouts and keyboard accessibility.
- Follow `.impeccable.md` for design context. Do not invent biographical details or project results.
